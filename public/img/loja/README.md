# Fotos da loja e da bancada

Coloque aqui as fotos reais do local, com estes nomes exatos (a seção "Sobre" da Home já busca por eles):

```
loja-1.jpg
loja-2.jpg
loja-3.jpg
bancada-1.jpg
bancada-2.jpg
bancada-3.jpg
```

- Formato `.jpg` (ou troque a extensão em `src/components/HomeAboutGallery.astro`, array `photos`, se preferir `.webp`).
- Proporção 4:3 (paisagem) combina melhor com o grid.
- Se uma foto não existir, o card mostra "Foto em breve" automaticamente — não quebra o layout.
