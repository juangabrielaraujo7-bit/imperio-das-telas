# Logo

Coloque aqui o arquivo da logo com o nome exato:

```
public/img/logo.png
```

- Formato `.png` (com fundo, como a arte que você enviou, ou transparente se preferir — funciona dos dois jeitos, o quadrado já tem cantos arredondados).
- Tamanho recomendado: pelo menos 128x128px (quadrada).
- Usada no Header e no Footer. Enquanto o arquivo não existir, aparece um quadradinho preto no lugar (sem quebrar o layout).

Se preferir usar `.svg` ou outro nome de arquivo, é só avisar que eu ajusto os componentes `Header.astro` e `Footer.astro`.
